# Changelog

All notable changes to this project are documented here.

## [1.1.0] - 2026-08-28

### Added

- Dark-mode window chrome, controls, disabled states, and dropdown menus.
- Matching heights across text fields, selectors, and program controls.
- Per-presenter custom image import with EXIF orientation handling, 16:9 center-cropping, and 1920×1080 normalization.
- One-click restoration of each bundled presenter silhouette.

### Changed

- Expanded automated coverage to ten tests.

## [1.0.0] - 2026-08-28

### Added

- Eight independent 1920×1080p30 NDI outputs.
- Eight centered, numbered, color-coordinated presenter silhouettes.
- Unique 48 kHz stereo identification tones for every presenter.
- Individual audio selection, Tone All, Silence All, and configurable Tone Chase modes.
- WPF control interface, persistent settings, and headless operation.
